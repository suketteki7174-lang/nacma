📖 PETUNJUK PENGGUNAAN & ALUR KERJA

Ikuti tahapan berikut secara berurutan untuk membuat laporan kunjungan lapangan dan menyiapkan dokumen pendukung.

1
Unggah PDF DRPUnggah file PDF DRP hasil unduhan dari aplikasi DRP-mu.
2
Baca PDF & Ambil DataKlik tombol Baca PDF & Ambil Data. Tunggu sampai proses pembacaan selesai. Tenang, prosesnya nggak sampai habis sebatang rokok, kok.... 😁
3
Isi Tanda Tangan PelaporYang penting mirip, jangan sampai tanda tangan sendiri malah lupa! 😂
4
Klik Simpan PDF Laporan (Kotak Warna Emas)File PDF akan dibuat, otomatis diunduh, dan disimpan di kotak merah LAP KUNJUNGAN. Jadi, nggak perlu repot mencari file ke mana-mana! 😁
5
Unggah Bukti Pengesahan SPPDCari dan klik tombol hijau Unggah Bukti Pengesahan, lalu unggah bukti SPPD yang sudah dibawa keliling desa dan kecamatan untuk minta pengesahan. Perjuangannya panjang, jalannya berliku, yang penting stempel dan tanda tangan berhasil terkumpul! 😂🚶‍♂️🏃‍♂️
6
Gabungkan 3 DokumenKlik tombol GABUNG 3 FILE. Aplikasi akan menyatukan PDF DRP, PDF Laporan Kunjungan, dan Bukti Pengesahan menjadi satu file ZIP. Akhirnya, tiga dokumen yang sudah diajak keliling desa dan kecamatan kini resmi bersatu. 😂
7
Bagikan ZIP / Pilih WhatsApp atau Unduh File ZIPKlik 📲 BAGIKAN ZIP / PILIH WHATSAPP untuk langsung membagikan file, atau klik ⬇️ UNDUH FILE ZIP untuk menyimpannya. Kalau semua sudah beres, lanjut gas sholawatan! Semoga berkas lancar sampai tujuan, rezeki lancar, dan tidak ada revisi susulan. 😂🤲
8
Kirim File Hasil PenggabunganKirim file ZIP hasil penggabungan kepada Korcam. Setelah terkirim, lanjut karaoke... eh, maksudnya SHOLAWATAN! 😂🎤🤲
Catatan: Pastikan ketiga dokumen sudah tersedia sebelum membuat ZIP. Jika menu berbagi tidak didukung browser, unduh file ZIP lalu lampirkan secara manual melalui WhatsApp. Gunakan browser dan perangkat yang sama agar file tersimpan di penyimpanan aplikasi.
